Research

研究项目

2026 — 至今ConcordOS面向自主智能体的 Linux 控制

我主导了 Planner、SDK 与 Gateway 的架构设计。智能体先在限定范围内读取工作空间，为计划中的步骤记录证据，再由 Core 审核并固定执行策略。执行器在 Linux 沙箱中按计划运行，并记录每一步的结果。

2026 — 至今Pero Agent Lab多智能体辅助钙钛矿材料发现

我设计了规划器与执行器协作的研究流程，串联文献检索、材料设计、筛选与报告撰写。不同角色通过 MCP 网关调用各自获准使用的科研工具，并提交报告供复核。

2026 — 至今SEU Agent Town校园尺度的生成式多智能体模拟

为模拟校园中跨天发生的互动，我设计了智能体之间的消息协议，并将记忆分为上下文、检索与整合三层，让过去的经历能够影响后续行为。

2024 — 2026Ophthalmic OCT眼科 OCT 图像分割与域泛化

我设计了跨域评估来观察分割模型在不同数据域上的表现，并研究域偏移、多模态预训练与迁移学习对模型泛化的影响。
